
# Potenciate Web

Proyecto base en React creado con Vite, siguiendo principios SOLID y arquitectura limpia.

## Estructura principal
- **src/domain**: Entidades y lógica de dominio
- **src/application**: Casos de uso
- **src/adapters**: Adaptadores/controladores
- **src/infrastructure**: Servicios externos/repositorios
- **src/shared**: Utilidades compartidas

## Herramientas de calidad
- ESLint y Prettier configurados para mantener buenas prácticas de código.

## Scripts principales
- `npm run dev`: Inicia el servidor de desarrollo
- `npm run lint`: Ejecuta ESLint
- `npm run build`: Compila la aplicación para producción

## Notas
- Sustituye los ejemplos por tu lógica de negocio real.
- Puedes expandir la arquitectura según crezcan los requerimientos.
