# Data Model

Firestore schema for Florece. All collections use auto-generated IDs unless noted.

## Collections Overview

| Collection | Purpose | Key Indexes |
|------------|---------|-------------|
| `cases` | User venture sessions | userId, status, createdAt |
| `products` | Product/service definitions | caseId, createdAt |
| `events` | Timeline events | caseId, type, date |
| `plans` | 7-day action plans | caseId, createdAt |
| `actions` | Individual tasks | planId, status, day |
| `evidence` | Proof files | actionId, userId, verificationStatus |
| `receipts` | Completion certificates | caseId, userId, generatedAt |
| `agent_runs` | Debug logs | caseId, userId, startedAt |

---

## Collection: `cases`

**Purpose**: User's venture journey from diagnostic to completion

**Document ID**: Auto-generated

**Schema**:
```typescript
{
  id: string;                          // Auto-generated doc ID
  userId: string;                      // Firebase Auth UID
  createdAt: Timestamp;                // Creation time
  updatedAt: Timestamp;                // Last update
  status: 'active' | 'completed';      // Current state
  answers: {                           // 5Q diagnostic responses
    product: string;                   // Q1: What to sell?
    customer: string;                  // Q2: Who are customers?
    cost: number;                      // Q3: Cost per unit
    price: number;                     // Q4: Price per unit
    hours: number;                     // Q5: Hours available/day
  };
  metadata: {
    location?: string;                 // e.g., "El Piñón, Magdalena"
    businessName?: string;             // e.g., "La Sofía"
  };
}
```

**Indexes**:
- `userId` (ascending) + `createdAt` (descending)
- `userId` + `status`

**Security Rules**:
```javascript
match /cases/{caseId} {
  allow read, write: if request.auth.uid == resource.data.userId;
}
```

**Example Document**:
```json
{
  "id": "case_abc123",
  "userId": "user_sofia_001",
  "createdAt": "2026-02-04T10:00:00Z",
  "updatedAt": "2026-02-04T10:15:00Z",
  "status": "active",
  "answers": {
    "product": "Comidas preparadas para llevar",
    "customer": "Vecinos que trabajan",
    "cost": 2,
    "price": 5,
    "hours": 3
  },
  "metadata": {
    "location": "El Piñón, Magdalena",
    "businessName": "La Sofía"
  }
}
```

## Collection: `products`

**Purpose**: Structured product/service extracted from diagnostic

**Document ID**: Auto-generated

**Schema**:
```typescript
{
  id: string;
  caseId: string;                      // Reference to parent case
  name: string;                        // Product name
  description: string;                 // Full description
  targetMarket: string;                // Customer segment
  category?: string;                   // e.g., "food", "service"
  createdAt: Timestamp;
}
```

**Indexes**:
- `caseId`

**Security Rules**:
```javascript
match /products/{productId} {
  allow read: if request.auth.uid == get(/databases/$(database)/documents/cases/$(resource.data.caseId)).data.userId;
  allow write: if request.auth.uid == get(/databases/$(database)/documents/cases/$(request.resource.data.caseId)).data.userId;
}
```

**Example**:
```json
{
  "id": "prod_xyz789",
  "caseId": "case_abc123",
  "name": "Comidas preparadas",
  "description": "Platos listos para llevar, hechos con ingredientes frescos",
  "targetMarket": "Trabajadores del vecindario sin tiempo para cocinar",
  "category": "food",
  "createdAt": "2026-02-04T10:05:00Z"
}
```

## Collection: `events`

**Purpose**: Timeline of milestones (diagnostic, plan created, action completed)

**Document ID**: Auto-generated

**Schema**:
```typescript
{
  id: string;
  caseId: string;
  userId: string;                      // Denormalized for queries
  date: Timestamp;
  type: 'diagnostic' | 'plan_created' | 'action_completed' | 'evidence_uploaded' | 'receipt_generated';
  data: Record<string, any>;           // Event-specific data
}
```

**Indexes**:
- `caseId` + `date` (descending)
- `userId` + `type` + `date`

**Example**:
```json
{
  "id": "evt_001",
  "caseId": "case_abc123",
  "userId": "user_sofia_001",
  "date": "2026-02-04T10:20:00Z",
  "type": "plan_created",
  "data": {
    "planId": "plan_xyz",
    "actionCount": 5
  }
}
```

## Collection: `plans`

**Purpose**: 7-day action plans generated by agent

**Document ID**: Auto-generated (prefix: `plan_`)

**Schema**:
```typescript
{
  id: string;
  caseId: string;
  productId: string;
  userId: string;                      // Denormalized for queries
  createdAt: Timestamp;
  horizon: '7days';                    // Always fixed at 7 days
  goals: string[];                     // 3-5 high-level goals
  unitEconomics: {
    cost: number;                      // Cost per unit
    price: number;                     // Price per unit
    margin: number;                    // Calculated margin (0-1)
    monthlyRevenue: number;            // Projected revenue
    monthlyProfit: number;             // Projected profit
  };
  days: Array<{
    day: number;                       // 1-7
    focus: string;                     // Theme for the day
  }>;
}
```

**Indexes**:
- `caseId` + `createdAt` (descending)
- `userId` + `createdAt`

**Example**:
```json
{
  "id": "plan_xyz",
  "caseId": "case_abc123",
  "productId": "prod_xyz789",
  "userId": "user_sofia_001",
  "createdAt": "2026-02-04T10:25:00Z",
  "horizon": "7days",
  "goals": [
    "Validate demand with 10 potential customers",
    "Create MVP menu with pricing",
    "Make first 3 sales"
  ],
  "unitEconomics": {
    "cost": 2,
    "price": 5,
    "margin": 0.6,
    "monthlyRevenue": 1500,
    "monthlyProfit": 900
  },
  "days": [
    {"day": 1, "focus": "Customer Discovery"},
    {"day": 2, "focus": "MVP Design"},
    {"day": 3, "focus": "Product Creation"},
    {"day": 4, "focus": "First Sales"},
    {"day": 5, "focus": "Feedback & Iterate"}
  ]
}
```

## Collection: `actions`

**Purpose**: Individual tasks in a plan

**Document ID**: Auto-generated (prefix: `act_`)

**Schema**:
```typescript
{
  id: string;
  planId: string;
  caseId: string;                      // Denormalized for queries
  userId: string;                      // Denormalized for queries
  day: number;                         // 1-7
  title: string;                       // Short action title
  description: string;                 // Full instructions
  status: 'pending' | 'in_progress' | 'completed' | 'verified';
  priority: 'high' | 'medium' | 'low';
  estimatedHours: number;              // 1-4 hours
  createdAt: Timestamp;
  startedAt?: Timestamp;               // When status → in_progress
  completedAt?: Timestamp;             // When status → completed
  verifiedAt?: Timestamp;              // When status → verified
}
```

**Status Transitions**:
```
pending → in_progress → completed → verified
```

**Indexes**:
- `planId` + `day` + `createdAt`
- `userId` + `status` + `day`
- `caseId` + `status`

**Security Rules**:
```javascript
match /actions/{actionId} {
  allow read: if request.auth.uid == resource.data.userId;
  allow update: if request.auth.uid == resource.data.userId &&
                   request.resource.data.keys().hasOnly(['status', 'startedAt', 'completedAt', 'verifiedAt']);
}
```

**Example**:
```json
{
  "id": "act_001",
  "planId": "plan_xyz",
  "caseId": "case_abc123",
  "userId": "user_sofia_001",
  "day": 1,
  "title": "Talk to 3 neighbors about prepared meals",
  "description": "Ask 3 neighbors if they would buy ready-to-eat meals for $5. Record their feedback.",
  "status": "verified",
  "priority": "high",
  "estimatedHours": 2,
  "createdAt": "2026-02-04T10:30:00Z",
  "startedAt": "2026-02-04T14:00:00Z",
  "completedAt": "2026-02-04T15:30:00Z",
  "verifiedAt": "2026-02-04T15:35:00Z"
}
```

## Collection: `evidence`

**Purpose**: Proof of action completion (files)

**Document ID**: Auto-generated (prefix: `evd_`)

**Schema**:
```typescript
{
  id: string;
  actionId: string;
  caseId: string;                      // Denormalized
  userId: string;                      // Denormalized
  fileUrl: string;                     // Firebase Storage gs:// URL
  fileName: string;                    // Original filename
  fileType: 'image' | 'audio' | 'document';
  fileSize: number;                    // Bytes
  uploadedAt: Timestamp;
  verificationStatus: 'pending' | 'approved' | 'rejected';
  verificationNotes?: string;          // Agent reasoning
  confidence?: number;                 // 0-1 confidence score
  verifiedAt?: Timestamp;
}
```

**Status Transitions**:
```
pending → approved
pending → rejected
```

**Indexes**:
- `actionId` + `uploadedAt` (descending)
- `userId` + `verificationStatus`
- `caseId` + `uploadedAt`

**Example**:
```json
{
  "id": "evd_voice_001",
  "actionId": "act_001",
  "caseId": "case_abc123",
  "userId": "user_sofia_001",
  "fileUrl": "gs://florece-dev/evidence/user_sofia_001/evd_voice_001/recording.m4a",
  "fileName": "neighbor_feedback.m4a",
  "fileType": "audio",
  "fileSize": 524288,
  "uploadedAt": "2026-02-04T15:30:00Z",
  "verificationStatus": "approved",
  "verificationNotes": "Clear recording of conversation with neighbor Maria. Confirms interest in buying meals at $5.",
  "confidence": 0.92,
  "verifiedAt": "2026-02-04T15:35:00Z"
}
```

## Collection: `receipts`

**Purpose**: Completion certificates

**Document ID**: Auto-generated (prefix: `rct_`)

**Schema**:
```typescript
{
  id: string;
  caseId: string;
  userId: string;
  planId: string;
  completedActions: number;            // Count of verified actions
  totalActions: number;                // Total actions in plan
  completionRate: number;              // 0-1 percentage
  generatedAt: Timestamp;
  certificateUrl?: string;             // Optional PDF/image
  message: string;                     // Congratulatory message
}
```

**Indexes**:
- `userId` + `generatedAt` (descending)
- `caseId` + `generatedAt`

**Example**:
```json
{
  "id": "rct_001",
  "caseId": "case_abc123",
  "userId": "user_sofia_001",
  "planId": "plan_xyz",
  "completedActions": 1,
  "totalActions": 5,
  "completionRate": 0.2,
  "generatedAt": "2026-02-04T15:40:00Z",
  "message": "💪 Every step counts! Keep going!"
}
```

## Collection: `agent_runs`

**Purpose**: Debug logs for agent execution

**Document ID**: Auto-generated (prefix: `run_`)

**Schema**:
```typescript
{
  id: string;
  caseId: string;
  userId: string;
  startedAt: Timestamp;
  completedAt?: Timestamp;
  status: 'running' | 'completed' | 'failed';
  error?: string;
  toolCalls: Array<{
    tool: string;                      // Tool name
    input: any;                        // Tool input
    output: any;                       // Tool output
    timestamp: Timestamp;
    durationMs: number;
  }>;
  geminiMessages: number;              // Count of API calls
  totalDurationMs?: number;
}
```

**Indexes**:
- `userId` + `startedAt` (descending)
- `caseId` + `status`

**Retention**: 30 days for debugging

**Example**:
```json
{
  "id": "run_001",
  "caseId": "case_abc123",
  "userId": "user_sofia_001",
  "startedAt": "2026-02-04T10:20:00Z",
  "completedAt": "2026-02-04T10:25:00Z",
  "status": "completed",
  "toolCalls": [
    {
      "tool": "computeUnitEconomics",
      "input": {"cost": 2, "price": 5, "monthlyVolume": 100},
      "output": {"margin": 0.6, "monthlyProfit": 300},
      "timestamp": "2026-02-04T10:20:15Z",
      "durationMs": 50
    },
    {
      "tool": "generatePlan",
      "input": {"caseId": "case_abc123", "hours": 3},
      "output": {"planId": "plan_xyz"},
      "timestamp": "2026-02-04T10:22:00Z",
      "durationMs": 2500
    }
  ],
  "geminiMessages": 3,
  "totalDurationMs": 5000
}
```

## Composite Indexes Required

Configure in Firebase Console or `firestore.indexes.json`:

```json
{
  "indexes": [
    {
      "collectionGroup": "actions",
      "queryScope": "COLLECTION",
      "fields": [
        {"fieldPath": "userId", "order": "ASCENDING"},
        {"fieldPath": "status", "order": "ASCENDING"},
        {"fieldPath": "day", "order": "ASCENDING"}
      ]
    },
    {
      "collectionGroup": "evidence",
      "queryScope": "COLLECTION",
      "fields": [
        {"fieldPath": "userId", "order": "ASCENDING"},
        {"fieldPath": "verificationStatus", "order": "ASCENDING"},
        {"fieldPath": "uploadedAt", "order": "DESCENDING"}
      ]
    }
  ]
}
```
